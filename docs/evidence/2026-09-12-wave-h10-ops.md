# Wave H10 — production smoke, observability and rollback contract

Date: 2026-09-12

## Findings

1. **The rollback contract document was never created.** The approved S+ plans
   (`Task 12C` / `Task 6.4`, issue #101) required
   `docs/operations/production-smoke-and-rollback.md`; `docs/operations/` did
   not exist. There was no documented rollback-vs-fix-forward path for a
   production site whose earlier blank-404 incident proved how much a bad
   release can matter.
2. **The smoke suite never checked the branded 404.** The earlier P0 (root
   `404.html` at 15 bytes) was verified by hand with `curl`, not by the suite
   that runs on every deploy. Writing the operations doc exposed the gap
   through its own contract test — the doc claimed a check the script did not
   perform.
3. **Observability was undocumented.** The site is deliberately telemetry-free
   (no analytics, no RUM, no cookies); that trade-off was not written down
   anywhere, so a future operator could mistake the absence of alerts for
   coverage.

## What changed

- **`docs/operations/production-smoke-and-rollback.md`**: deployment authority,
  post-deploy verification order (smoke with `SMOKE_COMMIT_SHA`, edge-header
  spot check, read-back ledger), the minimal observability model with its
  accepted residual risk, and the rollback-vs-fix-forward decision path
  (rollback to the previous Workers version, mandatory re-verification, fix
  through the normal gates — never out-of-band patching).
- **`scripts/smoke-production.mjs`**: new check — three unknown paths
  (EN, VI, root) must return **404** with branded content over 5 KB, so a blank
  404 stub can never ship unnoticed again.
- **`tests/architecture/operations-contract.test.mjs`**: keeps the doc present,
  linked from QA_STRATEGY, and honest — its claims are cross-checked against
  the smoke script and the security-surface contract.
- **`docs/QA_STRATEGY.md`** links the operations contract from the promotion
  section.

## Evidence (executed, production)

- `SMOKE_COMMIT_SHA=c7d2aa5 node scripts/smoke-production.mjs` against
  `https://blueskyzlabs.com` → **ALL PRODUCTION SMOKE CHECKS PASS**, including
  `PASS branded 404 is served on unknown paths` (EN, VI and root paths)
- `pnpm test:architecture` → **300 pass / 0 fail**

## Residual risk

- Rollback itself (dashboard action) is provider-private: it is documented and
  anchored to verification steps, but only the owner can execute it — recorded
  as such in the doc's ownership section.
- The observability gap is accepted residual risk, not coverage: no client-side
  telemetry until a provider/privacy decision exists (owner decision in
  `docs/current-work.json`).
