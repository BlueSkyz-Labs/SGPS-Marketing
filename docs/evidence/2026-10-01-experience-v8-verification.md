## 4. R3 decision record — `ShowcaseGroup.astro` phone rail `tabindex="0"`

**Decision: accept and record** (no code change) — the handoff explicitly allows "fix it without a new script file, or accept and record".

- The rail is a horizontally scrollable media strip. Its static `tabindex="0"` makes the scroll region keyboard-focusable where scrolling is the only way to reach off-screen items (below `64rem`), matching the WCAG scrollable-region-focusable practice.
- There is no existing script host on product pages to carry a JS-conditional variant without adding a **new** script file, which the handoff constraint forbids.
- At `>= 64rem` the strip does not scroll; the extra tab stop is a no-op for content access and harmless for AT.
- Re-evaluation hook: revisit if a product-page script host is added for other reasons, or if the rail becomes visible in full at all viewports.
