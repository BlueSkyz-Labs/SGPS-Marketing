**Landed skeleton (this card's base):**

- `src/lib/product-schema.ts` — optional `i18n.{vi,zh}` block (`shortDescription`, `jobs`, `capabilities`, `primaryActionLabel`); the build **fails** when a locale's `jobs`/`capabilities` count differs from English.
- `src/lib/product-copy.ts` — the single localized-copy resolver: `productCopy(data, lang)`, `statusLabelFor`, `lifecycleLabel`, `LIFECYCLE_LADDER`, `platformLabel`. English fields stay canonical for claim/proof binding, SEO provenance and truth tripwires; `data-product-status` and other machine attributes stay canonical English.
- Published set: Sổ Trọ (`hero`, order 1) and Sổ Tâm (`featured`, order 2). ApexAgent, FluentArc and VungTayLai stay in the registry with `public: false`, `featuredTier: hidden` (no page, card, sitemap or JSON-LD). All five keep vi/zh copy so re-publishing is a data flip. Guard: `tests/architecture/app-access-contract.test.mjs`.
- `appAccess` in the schema and `src/components/product/AppAccess.astro` on every profile: `signInUrl` (Sổ Trọ `https://sotro.blueskyzlabs.com/login`, Sổ Tâm `https://sotam.blueskyzlabs.com/auth/login`; ADR 0006 hosts, HTTP read-back 2026-09-28) and `android`/`ios` with `state: in-development` (no store link until `available` + `storeUrl`, schema-enforced). E2E: `tests/e2e/app-access.spec.ts`.
- Profile pages (`src/pages/{en,vi,zh}/products/[slug].astro`) render description, jobs, capabilities, CTA label, status text and endorsement through `productCopy`.
- `tests/architecture/product-i18n-contract.test.mjs` — every public product has mirrored vi/zh; localized copy cannot reintroduce out-of-scope claims.

**Architecture decision (supersedes W3.4's “locale maps”):** a parallel `i18n` block keeps the English record byte-stable for the existing provenance/tripwire gates and makes localization additive. Public products must carry both locales (contract test). Do not add a second copy source — every component reads `productCopy`.

**Reference implementation:** commits `ad178ae`, `6af7e82`, `cd02cdd` (PR #302 history, local-only branches are not needed). Read a hunk with `git show <sha> -- <path>`; adapt it to the Brand Kit v4 surfaces, never paste over newer `main`.
