# Web implementation quick start

## Recommended HTML head
```html
<link rel="icon" href="/icons/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/icons/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png">
<link rel="manifest" href="/icons/site.webmanifest">
<meta name="theme-color" content="#0B1020">
```

## Social metadata
```html
<title>BlueSkyz Labs - Intelligence. Elevated. Impact.</title>
<meta name="description" content="BlueSkyz Labs builds intelligent products that empower people and elevate the way work gets done.">
<meta property="og:title" content="BlueSkyz Labs - Intelligence. Elevated. Impact.">
<meta property="og:description" content="Intelligent products for a brighter tomorrow.">
<meta property="og:image" content="https://blueskyzlabs.com/assets/open_graph_1200x630.png">
<meta property="og:url" content="https://blueskyzlabs.com/">
<meta property="og:type" content="website">
<meta name="twitter:card" content="summary_large_image">
```
